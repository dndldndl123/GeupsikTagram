# 급식타그램

우리 학교 급식 조회·소통 프로그램

월별 달력으로 조식·중식·석식을 조회하고, 메뉴별 코멘트와 좋아요로 의견을 나누는 WPF 프로그램입니다.

## 폴더 구성

| 폴더 | 내용 |
|---|---|
| `중간프로젝트 클라이언트/` | WPF 클라이언트 (C#, XAML) |
| `중간프로젝트/` | SchoolmealAPI 서버 (ASP.NET Core Web API, MySQL) |

## 주요 기능

- 로그인 / 회원가입
- 월별 급식 달력 (평일, 조식·중식·석식)
- 메뉴별 코멘트 · 좋아요
- 이달의 급식 TOP 3
- NEIS 급식 OpenAPI 연동

## 실행 방법

1. MySQL에 `schoolmeal` 데이터베이스를 준비합니다.
2. `중간프로젝트/중간프로젝트/appsettings.example.json`을 복사해서 같은 폴더에 `appsettings.json`으로 저장하고, DB 비밀번호와 NEIS API 키를 입력합니다.
3. `중간프로젝트/중간프로젝트.sln`을 열어 서버를 실행합니다.
4. `중간프로젝트 클라이언트/중간프로젝트 클라이언트.sln`을 열어 클라이언트를 실행합니다.
